# StudentManagementSystem
Name: Noarh Tariq
Ejada Training - Week 1 Assignment

About the project
This is a console application built in Java. It manages student records - you can add
students, give them marks, and see their average and grade.

## How to run
Open the project in Eclipse.
Inside the src folder you'll find two classes: Student and StudentManagementapp.
Run StudentManagementapp (it has the main method).
You'll see a menu in the console with numbers 1 to 6, just type the number you want.


Classes I used
Student - this class represents one student. It stores the id, name, and a list of
marks. It also has the methods that calculate the average and the grade, and a
method to print the student's info.

StudentManagementapp - this is where the program starts. It shows the menu, takes
what the user types, and calls the correct method for each choice.

 ## Features


Add a new student (won't let you use an ID that's already taken, and name can't be empty)
Add a mark to a student (has to be between 0 and 100)
Display all the students
Search for one student using their ID
Show which student has the highest average
Exit the program
